# Simple-Linux-Upgrade-Scripts
### Doing what Windows is struckling with


Select the version fitting to your Linux Distro (apt or pacman)
Download to your home directory
Mark the script as executable and remove write permissions:

```
sudo chmod +x <the-verion-of-your-script>.sh
sudo chmod u-w <the-verion-of-your-script>.sh
```
Run each time you wish to Upgrade your System and or want to Reboot / Shutdown
